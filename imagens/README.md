# 3. Evidências Visuais

## 3.1 Finalidade

Esta pasta está destinada ao armazenamento de imagens relacionadas ao desenvolvimento e à documentação do projeto **Amazon Rekognition — Análise de Imagens**.

## 3.2 Organização

As imagens poderão ser utilizadas para complementar a documentação quando houver materiais visuais disponíveis, mantendo uma relação clara entre cada evidência e a etapa correspondente do projeto.

### Estrutura sugerida

```text
imagens/
├── 01-processo/
├── 02-funcionalidades/
├── 03-resultados/
└── 04-evidencias-gerais/
```

As subpastas acima representam uma organização futura. Elas não são criadas enquanto não houver arquivos para armazenar, evitando manter diretórios vazios apenas para preencher a estrutura do repositório.

## 3.3 Situação atual

No momento, esta pasta contém apenas este arquivo de documentação. Não há imagens a serem adicionadas nesta etapa do projeto.

## 3.4 Critério para inclusão de imagens

Quando houver imagens disponíveis, elas deverão:

- estar relacionadas diretamente ao projeto;
- possuir identificação clara;
- ser utilizadas como complemento da documentação;
- estar vinculadas à etapa ou funcionalidade correspondente;
- representar informações reais do processo documentado.
